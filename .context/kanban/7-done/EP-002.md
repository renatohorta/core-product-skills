# EP-002 — cp-ui — design system before code, UI audit after code

## Goal
Products built through the cp-* pipeline are generic and full of UI bugs. Give the pipeline a design system decided by the operator before code, and a UI audit after code whose findings enter the pipeline as BUGs.

## Scope
In: skill cp-ui (--design-system, --audit, --verify), vendored UUPM v2.15.0, hooks in cp-build/cp-review/cp-analysis-design/cp-orchestrator. Out: generating UI code, making Playwright a requirement, a coverage ledger, native-app visual audit.
